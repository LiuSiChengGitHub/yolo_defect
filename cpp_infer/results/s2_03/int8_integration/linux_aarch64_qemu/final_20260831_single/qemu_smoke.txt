Scope:
  Loads and validates RuntimeConfig + ModelArtifactSpec.
  Optional --image keeps the existing OpenCV preprocess smoke.
  --inspect-model creates an ORT CPU session, reads actual model
  metadata, and validates it against the artifact contract.
  --raw-output-summary preprocesses one image, runs one synchronous
  raw inference, and prints only bounded tensor summaries.
  --output-json and --output-image run the S1-05 single-image
  pipeline: preprocess, ORT inference, tested postprocess, and files.
  --benchmark runs the Release-only S1-08 batch-1 CPU protocol.
  Defaults are --warmup 10 and --repeat 100. It reports mean/P50/P95
  for image decode, preprocess, Session::Run, postprocess, pipeline,
  and end-to-end, then writes machine-readable --benchmark-json.
  Session/model initialization, statistics, JSON writing, and drawing
  are outside repeated timing; drawing is not executed.
  --profile creates a separate profiling-enabled ORT session, runs
  the fixed preprocessed image (default 10 times), calls EndProfiling,
  and reports the actual ORT-generated JSON trace path. Profile timing
  contains instrumentation overhead and is not benchmark evidence.
  --batch discovers deterministic tasks and runs a bounded queue.
  Each worker owns one existing batch=1 DetectorPipeline/ORT session;
  JSON is written per success and --output-images also writes PNG.
  Directories are recursive and sorted; UTF-8 manifest paths remain
  in declaration order and resolve from the manifest directory.
  Output parents are created recursively. Existing regular files are
  rejected unless --overwrite is explicit; paths matching protected
  inputs are rejected before writing. Relative CLI image/output paths
  use the current working directory. No GUI, true ONNX batch, video,
  service, GPU concurrency, or lock-free queue exists.
